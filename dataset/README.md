## 📂 Dataset
Due to file size limitations, the dataset is not included in this repository. 
1. Download the ASL alphabet datasets from
   - [Detection Dataset](https://www.kaggle.com/datasets/ammarnassanalhajali/american-sign-language-letters)
   - [Classification Dataset](https://www.kaggle.com/datasets/krishnapaanchajanya/american-sign-language-asl?select=American+Sign+Language+%28ASL%29)
   - [Personal Photos Dataset](personal-photos/)
3. Place the extracted dataset folder inside the `dataset/` directory of this project before running the training or inference scripts.
